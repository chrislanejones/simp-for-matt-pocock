# ADR Best Use Cases Resources

Sources checked on **2026-11-05**.

## Knowledge

- [Michael Nygard: Documenting Architecture Decisions](https://www.cognitect.com/blog/2011/11/15/documenting-architecture-decisions)
  Original 2011 account of short records for significant decisions. Use for the rationale, basic sections, consequences, and preservation of superseded decisions.

- [ADR GitHub organization: Motivation and Definitions](https://adr.github.io/)
  Defines ADRs and decision logs, and links different templates. Use to separate the underlying practice from one organization's preferred format.

- [AWS Prescriptive Guidance: Architectural decision record process](https://docs.aws.amazon.com/prescriptive-guidance/latest/architectural-decision-records/adr-process.html)
  Concrete scope and a proposed-to-accepted review workflow. Use for examples of architectural significance and discussion of team ownership; its process is guidance, not a universal mandate.
